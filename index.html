PROJECT 01 · MSc DISSERTATION · FEATURED

Multimodal RAG for Structured Financial Document Extraction

Developed a multimodal Retrieval-Augmented Generation system for extracting structured financial information from heterogeneous financial documents. The system combined visual document processing, multimodal AI, embeddings and semantic retrieval to improve the reliability of information extraction.

Python Azure OpenAI RAG FAISS PyMuPDF Embeddings Multimodal AI
View full project →

Overview

This MSc Data Science dissertation investigated how multimodal Retrieval-Augmented Generation can be used to extract crucial financial information from complex and inconsistently formatted financial reports.

Financial documents frequently contain information inside tables, footnotes and visually structured pages. Conventional text extraction can lose important relationships between financial labels and their corresponding values. The project therefore adopted a vision-first document-processing approach.

Objective

  • Investigate the effectiveness of multimodal RAG for financial information extraction.
  • Evaluate whether vision-based extraction improves the preservation of document structure.
  • Investigate the effect of retrieval grounding on response reliability.
  • Evaluate the influence of document structure and extraction quality on system performance.

Methodology

PDF documents were processed using PyMuPDF. Individual pages were rendered as images and supplied to an Azure OpenAI multimodal model.

The model extracted visible information while preserving financial tables using Markdown. Page-level representations were subsequently converted into embeddings using an Azure OpenAI embedding model.

The embeddings were indexed using FAISS. When a user submitted a query, the system retrieved the most relevant document content and supplied it to the language model as contextual evidence.

This retrieval-grounded approach was designed to reduce unsupported responses and ensure that extracted financial information was based on the contents of the source documents.

Key Findings

The results demonstrated that the multimodal extraction and retrieval approach was highly effective at locating and returning the required financial information.

The project also highlighted the importance of preserving the visual structure of financial documents. Tables and their relationships cannot always be represented effectively through conventional plain-text extraction.

PROJECT 02 · MACHINE LEARNING

SVM vs CNN — Adult Income Classification

Comparative study of a Support Vector Machine and a CNN-based neural network for income classification using the Adult Income dataset.

Python Scikit-learn PyTorch SVM CNN Classification
View full project →

Overview

This project compared traditional machine learning and neural-network approaches to classification using the Adult Income dataset.

Dataset

The Adult Income dataset contains approximately 48,842 records and 14 attributes. The objective was to classify individuals according to their income category.

Data Preparation

  • Categorical variables were encoded using LabelEncoder.
  • Numerical features were standardised using StandardScaler.
  • The dataset was divided using an 80:20 train/test split.

Support Vector Machine

A linear-kernel Support Vector Machine was developed as the traditional machine-learning baseline.

Convolutional Neural Network

A CNN-based neural network was implemented using PyTorch and adapted for the tabular dataset. The model used DataLoader, CrossEntropyLoss and the Adam optimiser and was trained for 10 epochs.

Results

Model Accuracy Higher-Income Recall Higher-Income F1
SVM 82% 30% 44%
CNN 85% 61% 66%

Key Finding

The CNN achieved higher overall accuracy and substantially improved detection of the higher-income class. The project demonstrated why accuracy alone can be misleading when evaluating classification problems with uneven class distributions.

Banknote Authentication

Neural Computing Machine Learning Classification Data Analysis

Overview

This Neural Computing project investigated the use of machine-learning techniques to distinguish genuine banknotes from counterfeit examples using numerical characteristics derived from banknote images.

Dataset

The Banknote Authentication dataset contains numerical measurements derived from images of banknotes. These measurements provide features that can be used for binary classification.

Methodology

  • Dataset inspection
  • Feature and target preparation
  • Data preprocessing
  • Neural model development
  • Model training
  • Prediction
  • Performance evaluation

Classification Problem

The model was designed to distinguish between genuine and counterfeit banknotes based on the numerical characteristics contained within the dataset.

Key Learning

The project provided practical experience in applying neural computing to a real-world binary classification problem and demonstrated the importance of preprocessing, model configuration and appropriate evaluation.
